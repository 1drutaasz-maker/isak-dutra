# FinanceFlow

Controle de orçamento pessoal — projeto demonstrativo de portfólio.

## Funcionalidades

Cadastre receitas e despesas, acompanhe saldo, entradas e saídas e exclua registros.

## Como executar

Abra [index.html](./index.html) em um navegador moderno. Não requer instalação ou backend.

## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- JavaScript moderno (DOM, eventos e localStorage)

## Regra principal

Saldo = soma das receitas − soma das despesas.

## Limitações

Valores de exemplo são armazenados apenas no localStorage. Não conecta a contas bancárias.

## Próximas melhorias

- Testes automatizados
- Acessibilidade e refinamento da experiência do usuário
- Exportação/importação de dados
