# NutriCalc

Calculadora nutricional didática — projeto demonstrativo de portfólio.

## Funcionalidades

Cadastre nutrientes e suas quantidades por 100 g, ajuste o peso da porção e calcule quantidades proporcionais.

## Como executar

Abra [index.html](./index.html) em um navegador moderno. Não requer instalação ou backend.

## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- JavaScript moderno (DOM, eventos e localStorage)

## Regra principal

Quantidade na porção = quantidade por 100 g × peso da porção / 100.

## Limitações

Valores devem ser fornecidos pelo usuário; a aplicação não valida dados nutricionais e não gera rótulos regulamentares.
