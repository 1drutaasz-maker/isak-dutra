# StudyHub

Gerenciador de tarefas de estudo — projeto demonstrativo de portfólio.

## Funcionalidades

Cadastre uma atividade e matéria, avance de pendente para concluída e acompanhe o progresso.

## Como executar

Abra [index.html](./index.html) em um navegador moderno. Não requer instalação ou backend.

## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- JavaScript moderno (DOM, eventos e localStorage)

## Regra principal

Progresso = atividades concluídas / total.

## Limitações

O estado das tarefas fica somente neste navegador.

## Próximas melhorias

- Testes automatizados
- Acessibilidade e refinamento da experiência do usuário
- Exportação/importação de dados
