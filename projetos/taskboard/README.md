# TaskBoard

Quadro Kanban simplificado — projeto demonstrativo de portfólio.

## Funcionalidades

Crie tarefas, defina responsável e avance entre A fazer, Em andamento e Concluído.

## Como executar

Abra [index.html](./index.html) em um navegador moderno. Não requer instalação ou backend.

## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- JavaScript moderno (DOM, eventos e localStorage)

## Regra principal

Cada clique em Avançar etapa percorre as três colunas de status.

## Limitações

Os dados são locais; não há sincronização entre usuários.

## Próximas melhorias

- Testes automatizados
- Acessibilidade e refinamento da experiência do usuário
- Exportação/importação de dados
